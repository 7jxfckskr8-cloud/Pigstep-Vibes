# Pigstep Vibes

A standalone Minecraft music disc jukebox.

## Run locally

```bash
npm install
npm start
```

## Build a Mac app

```bash
npm run package:mac
```

The finished `.dmg` and `.zip` files are created in `dist/`.

## Build for Windows 10/11

```bash
npm run package:win
```

The finished Windows installer and ZIP are created in `dist/`.
